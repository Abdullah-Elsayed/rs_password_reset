# Password Strength Validator

## Description
This module adds comprehensive password strength validation for Odoo 15 password reset functionality.

## Features
- Real-time password strength meter
- Visual feedback with color-coded strength indicator
- Password requirements checklist
- Password match validation
- Disabled submit button until all requirements are met

## Password Requirements
- Minimum 8 characters
- At least one uppercase letter
- At least one lowercase letter
- At least one digit
- At least one special character

## Installation
1. Download and extract the module to your Odoo addons directory
2. Restart Odoo server
3. Update Apps List
4. Install "Password Strength Validator"

## Usage
The module automatically activates on password reset pages. Users will see:
- Password strength meter (Weak/Medium/Strong)
- Requirements checklist with real-time updates
- Password match indicator
- Disabled submit button until all criteria are met
